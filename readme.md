# TARDIS Invaders
Space Invaders (Doctor Who Edition) built in Python using Pygame but with LAN multiplayer AKA **TARDIS invaders**

## How to play (itch.io )
1. Download the ZIP
2. Extract it
3. Run 'main.exe'

## Gameplay Vid 
https://streamable.com/axydo6

## Solo Mode
- Press SPACE on the start screen.

## Host Multiplayer
- Press H
- Your IP address will appear
- Wait for the other player to enter your IP
- Press ENTER to start

## Join Multiplayer
- Press J
- Enter the host’s IP
- Wait for the host to start

**Both computers must be on the same wifi network**

## Notes:
* The game uses a client‑server model over TCP sockets
* Both players must stay connected for the round to work
* If the game crashes, restart both host and joiner
* You can't replay a multiplayer round. Both players have to relaunch the game. Well, the option is there but its super funky. 

## Controls
* **Left / Right arrows**: move
* **Space**: shoot
